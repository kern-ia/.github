# Support

Kern is in design phase; there is no general help channel yet.

- **Found a bug?** Open a bug report in the affected repository (Issues → New issue → Bug report).
- **Want a feature or behavior change?** Open a feature request.
- **Design question, new package proposal, cross-package concern?** Open an RFC issue — see the [brick test](https://github.com/kern-ia/.github/blob/main/docs/brick-test.md) for what a package proposal must answer.
- **Security problem?** Never open a public issue — see [SECURITY.md](https://github.com/kern-ia/.github/blob/main/SECURITY.md).

Start with the [org profile](https://github.com/kern-ia) and the [conventions docs](https://github.com/kern-ia/.github/tree/main/docs) — most "how is this meant to work" questions are answered there.
